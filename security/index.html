Privacy and security

Guest names stay with the maison.

A client list is a maison's most private asset. This page sets out how Ellie protects it, as it stands today, and what is still being written before launch.

Who sees what

The maison owns the names. Everyone else works with a code that means nothing outside the event.

How the file is protected

Encrypted field by field
Each name, contact detail, passport number and preference is encrypted on its own (AES-256-GCM). Each organisation has its own data key, itself encrypted by a master key kept apart from the data.
Found without being exposed
Searching a guest by name uses keyed fingerprints of the name (blind indexes), so names are never stored in clear, even to be searched.
Nothing in the margins
No guest data in logs, in web addresses or in error messages.

Who can get in

Two-factor sign-in
Required for every account, set up at the first sign-in with an authenticator app, with encrypted backup codes.
Passwords and sessions
Passwords hashed with Argon2id, sessions held in secure cookies that scripts cannot read, sign-in attempts limited.
Roles on two levels
The organisation (a maison or an agency), then the event: owner, manager or viewer. A viewer reads and changes nothing.
Every change recorded
An append-only record of who changed what, and when.

The assistant works with codes

Ask Ellie runs on Anthropic's Claude, through its API. Before any text leaves Ellie for the model, guest names are replaced by their codes.

Names replaced first
Names found in a question or in the event are replaced by guest codes before anything is sent. The masking is tested against deliberate attempts to get round it.
What it does receive
Codes, tiers, journeys, and notes such as dietary requirements, without names: the assistant cannot help with a dinner without them.
It proposes, a person decides
The assistant can only prepare a change. Nothing is written until someone with the right to make that change confirms it.
A spending limit
Each organisation has a monthly limit on assistant use.

Still being written

Ellie is in pilot. These points will be settled and published here before launch; until then, ask us.

Ask about security
  • Hosting: Ellie runs on Amazon Web Services. The region where the data lives to confirm.
  • How long event data is kept, and how it is deleted after an event to write.
  • The list of sub-processors (hosting, email delivery, the language model) and the agreements with each to publish.
  • An independent security review to plan.

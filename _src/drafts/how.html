How it works

From the first guest list to the last car.

Weeks before

Create the file

The guest list arrives as a spreadsheet. Ellie reads it into one file and tells you what to fix before anything is imported. Then the programme is built module by module, rooms, cars, dining, venue, and sent to the maison for approval.
